// Why ChaldOS

Everything included, nothing wasted

Gaming-ready out of the box.

Gaming-ready

Steam, Proton, MangoHud, vkBasalt and more — pre-installed and configured so you can play right away.

Immutable base

Built on Fedora Atomic with ostree. Your system stays stable and you can always roll back.

KDE Plasma

Ships with KDE Plasma — fast, customisable, modern. A GNOME edition is also available.

Patched kernel

HDR support, extra hardware compatibility, and performance patches baked right in.

Flatpak + Distrobox

Install apps as Flatpaks or run any Linux distro inside Distrobox containers.

Open source

Fully open source and community-driven. Fork it, modify it, make it entirely yours.
