## 📖 About

ChaldOS is a Fedora-based Linux distribution focused on delivering a polished, out-of-the-box experience. Built on the solid foundation of Fedora, it brings enhanced hardware support, a curated software selection, and a streamlined setup process.

> 🌐 Website: [chalds-mods.github.io/ChaldOS-Uranus](https://chalds-mods.github.io/ChaldOS-Uranus/)

## 💻 System Requirements

### Minimum

| Component    | Requirement                         |
|--------------|-------------------------------------|
| **CPU**      | x86_64, 2 cores @ 2 GHz            |
| **RAM**      | 4 GB                                |
| **Storage**  | 50 GB free space                    |
| **GPU**      | Any GPU with Mesa or NVIDIA drivers |
| **Boot**     | UEFI required                       |
| **Internet** | Not required                        |
| **Power**    | Battery or UPS will do *(optional)* |

### Recommended

| Component    | Requirement                                  |
|--------------|----------------------------------------------|
| **CPU**      | x86_64, 6+ cores @ 3.5 GHz                 |
| **RAM**      | 16 GB DDR4/DDR5                             |
| **Storage**  | 100 GB+ NVMe SSD                            |
| **GPU**      | Dedicated GPU (NVIDIA RTX / AMD RX)         |
| **Boot**     | UEFI + Secure Boot off                      |
| **Internet** | Broadband for updates & gaming              |
| **Power**    | Stable 220V / 110V recommended *(optional)* |

## 🚀 Installation

1. Download the latest ISO from [our website](https://chalds-mods.github.io/ChaldOS-Uranus/)
2. Flash it to a USB drive (e.g. with [Ventoy](https://www.ventoy.net/) or [Balena Etcher](https://etcher.balena.io/))
3. Boot from the USB and follow the installer
4. Enjoy!
